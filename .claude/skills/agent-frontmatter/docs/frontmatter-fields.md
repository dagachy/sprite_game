# 에이전트 frontmatter 필드 (ex-07-13 원칙)

## 필수 4필드

| 필드 | 사유 |
|------|------|
| `name` | 에이전트 식별자. 호출 시 사용. 누락 시 로드 실패. |
| `description` | 라우팅 판단 근거. 호출자가 이걸 읽고 적합성 판단. |
| `model` | 사용 모델 계열(`sonnet` / `opus` / `haiku`). 비용·속도 트레이드오프 선언. |
| `tools` | 허용 도구 목록. 권한 과소/과잉 방지. 역할 적합성은 별도 스킬이 점검. |

## 권장 필드

| 필드 | 사유 |
|------|------|
| `color` | UI 식별 팔레트. 다중 에이전트 운영 시 가독성. |

## 본문

- 최소 3줄 이상의 역할·규칙·입출력 계약 서술 필수.
- 책 ex-07-13 기준: "에이전트는 설명이 아니라 명령형 프롬프트여야 한다".

## 범위 밖

- `model` 값이 유효한 enum인가 (예: `claude-sonnet-4-6`) — 별도 스킬.
- `tools` 가 역할에 적합한가 (예: read-only 역할에 Write 있는가) — `agent-tools-contract`.
- 본문 품질 (명령형인가, 모호한가) — `prose-pruner`.
