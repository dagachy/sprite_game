# 컨텍스트 절약 3원칙

LLM 컨텍스트(토큰)는 비용이 높으므로, 에이전트 문서(SKILL.md, AGENT.md)는 **의도적으로 짧고 정확**하게 작성해야 한다.

## 3원칙 표

| 원칙 | 대상 | 판정 | 행동 | 예시 |
|---|---|---|---|---|
| **1. 일반 지식 제거** | 표준 언어·라이브러리 문법/API | 누구나 아는가? | ❌ 삭제 | `JSON은...` → 삭제 |
| **2. 도메인 관례 추가** | 팀/프로젝트 고유 규칙·도구 | 여기서만 유효한가? | ✅ 추가 | `GrepBridge로 검색` 같은 규칙 |
| **3. 산문 압축** | 장황한 설명·경어체 표현 | 다시 말할 수 있는가? | 🔨 압축 | 3문단 → 예시 1줄 + 명령형 |

## 상세 설명

### 원칙 1: 일반 지식은 삭제
표준 언어/라이브러리의 공개 문서에 있는 내용을 반복하지 않는다.
- ❌ 삭제: Python `list.append()` 동작, JSON 포맷, Git 의미
- ✅ 보존: 팀 커밋 규칙, 프로젝트 특화 도구

### 원칙 2: 도메인 관례는 추가
이 팀·프로젝트에서만 유효한 규칙, 도구, 흐름을 명시한다.
- ❌ 누락하면 안됨: GrepBridge, 폴더 구조, 에이전트 역할
- ✅ 추가 형태: `이 팀은 [도구]를 사용`, `[구조]:...`

### 원칙 3: 산문은 압축
같은 뜻을 명령형·예시로 단축한다 (30% 이상 줄이기).
- ❌ 압축 대상: 경어체 다단락 설명
- ✅ 압축 후: 명령형 + 예시 1줄
