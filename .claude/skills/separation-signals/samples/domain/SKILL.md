# kpi-calculator

부서별 KPI 지표를 산출한다.

## 언제 사용하나

- "KPI 계산해줘", "지표 뽑아줘"라고 요청할 때
- 정기 보고서에 넣을 핵심 지표가 필요할 때

---

## 흐름

### 1단계: 부서 확인

사용자에게 어느 부서의 KPI를 산출할지 확인한다.

```
어느 부서의 KPI가 필요하신가요?
1. 매출팀
2. 재고팀
```

---

### 2단계: 부서별 산출

**매출팀이면** 다음 지표를 계산한다.

- 매출 성장률: (이번 달 매출 - 지난달 매출) / 지난달 매출 × 100
- 전환율: 구매 완료 수 / 방문자 수 × 100
- 객단가: 총 매출 / 주문 수

```bash
python3 kpi/sales.py \
  --period {PERIOD} \
  --output kpi-sales.json
```

산출 결과 예시:
```
매출 성장률: +12.4%
전환율: 3.8%
객단가: 42,500원
```

---

**재고팀이면** 다음 지표를 계산한다.

- 재고 회전율: 기간 내 출고량 / 평균 재고량
- 품절률: 품절 발생 SKU 수 / 전체 SKU 수 × 100
- 재고 정확도: 실사 재고 / 시스템 재고 × 100

```bash
python3 kpi/inventory.py \
  --period {PERIOD} \
  --output kpi-inventory.json
```

산출 결과 예시:
```
재고 회전율: 4.2회
품절률: 1.3%
재고 정확도: 98.7%
```

---

### 3단계: 결과 출력

산출된 KPI를 사용자에게 보고한다.

결과 형식:
- 지표명: 수치 (전기 대비 변화)
- 목표 달성 여부 (config/kpi-targets.json 기준)
